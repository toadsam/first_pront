# first_pront

HTML, CSS, JavaScript로 만든 첫 프론트엔드 웹페이지 실습 저장소입니다. 넷플릭스 스타일의 콘텐츠 소개 화면을 직접 구성하며 정적 웹 페이지 제작 흐름을 연습합니다.

## 프로젝트 개요

`first_pront`는 프론트엔드 학습 초기에 만든 정적 웹 프로젝트입니다. 이미지 에셋, HTML 구조, CSS 스타일링, JavaScript 동작을 한 폴더 안에서 구성해 브라우저에서 바로 확인할 수 있습니다.

## 주요 내용

- HTML 기반 페이지 구조 작성
- CSS를 이용한 레이아웃과 스타일링
- JavaScript 파일 분리
- 이미지와 포스터 에셋 활용
- 정적 웹 페이지 구성 연습

## 기술 스택

- HTML
- CSS
- JavaScript

## 폴더 구조

```text
.
├── README.md
└── 넷플리스 현재민 홈페이지 만들기/
    ├── np.html
    ├── styles.css
    ├── script.js
    └── 이미지 에셋
```

## 실행 방법

별도 빌드 과정은 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `넷플리스 현재민 홈페이지 만들기/np.html` 파일을 브라우저로 엽니다.
3. HTML, CSS, JavaScript를 수정하며 화면 변화를 확인합니다.

## 학습 포인트

- 정적 웹 프로젝트의 기본 파일 분리 방식
- 이미지 에셋을 웹 페이지에 배치하는 방법
- CSS로 카드형 콘텐츠를 구성하는 방법
- JavaScript를 별도 파일로 분리해 연결하는 방법
